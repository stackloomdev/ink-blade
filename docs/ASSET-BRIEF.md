# 《墨刃》素材生成与建模交接

## 已确定的主角

以 [用户提供的原始设定图](../assets/reference/hero-direction.png) 为角色与动作方向：年轻东方男性，黑色长发与散碎刘海，黑色不对称披肩，墨染白色交领内衫，分片长衣摆，黑色护臂与长靴，暗朱红系带，金属腰饰，单手长刀与腰后刀鞘。主角不戴斗笠、不蒙面；斗笠留给刀客敌人。

参考图中的红色刀光只作为绝技方向；普通连斩保持白刃、飞墨，腰带可以保留少量暗红。

原图为 1536×1024 的概念总览，不是三维模型。虽然 PNG 文件带 alpha 通道，画面里仍有可见底色、文字与特效；动作小图大多只有数十到一百余像素高，尺寸、脚底位置与相邻帧连续性也未统一，不能直接充当成品动画图集。文件已原样保留。

## 已经接入什么

- `src/warrior.js` 的主角按上述轮廓重塑，仍接入现有跑动、连斩、空中斩、弹反、冲刺和处决逻辑。
- 新增分束长发、黑白叠衣、墨染衣摆、腰间红绳与挂饰；头发和衣片跟随动作。
- [GLB 建模底稿](../assets/models/hero-reference-blockout.glb) 与 [Blender 文件](../assets/models/hero-reference-blockout.blend) 可以继续编辑。
- 模型是基础版，脸部、纹理和布料尚未达到原画精度。GLB 包含网格及关节父子结构，**没有蒙皮骨骼或动画片段**；游戏动作、刀路和布料变形仍由代码驱动。GLB 的标准材质也不包含游戏卡通光照与后期。

在开发服务中打开 `/tools/character-study.html` 可放大主角，检查正面、侧面、背面、命中帧，或重新导出 GLB。

## 下一批先生成这些

这些尺寸是本项目交接要求，不是生成工具的通用限制。优先按单张、单用途生成，避免再次把几十个人物塞进一张总览图。

| 优先级 | 素材 | 建议交付 | 用来解决什么 |
| --- | --- | --- | --- |
| P0 | 主角正、侧、背三视图 | 三张独立 PNG，每张 1024×1536；正交视角、同一 A-pose、同一比例与脚底高度 | 确认侧脸、发束、背部披肩、衣服层次与刀鞘挂法；不要把未知的背面结构当成已定稿 |
| P0 | 主角脸部与发型细节 | 正面、侧面各一张，至少 1024×1024；无夸张表情 | 细化五官、刘海与发束，减少当前模型的简化感 |
| P0 | 长刀与刀鞘独立设定 | 2048×1024；刀、鞘分开摆放，完整侧视，无手和特效 | 确认刀弧、刃线、护手、握柄、刀鞘和红绳结构 |
| P1 | 白袍剑客三视图 | 三张独立 1024×1536；同一 A-pose | 建立与主角明确不同的 Boss；三阶段共用同一人，不生成三个不同造型 |
| P1 | 斗笠刀客与长枪兵设定 | 每人一张全身正侧对照，单人至少 1024×1536 | 避免普通敌人只是主角换色；强调各自武器与轮廓 |
| P2 | 古寺、山石和竹林的风格稿 | 先出一张 2560×1440 关键场景 | 用来统一气氛、建筑尺度与构图；正式背景如需替换，再交付远山、竹林、寺门等分层素材 |

最小第一批：**主角三视图三张 + 武器设定一张**。先检查一致性，再继续脸部与 Boss。单张侧面视图应保持角色右侧视角；武器若遮挡身体，可在人物三视图里暂时移出手持位置，另出武器图。

## 可直接使用的生成提示词

每次附上同一张原始设定图作为人物参考，并明确此次只要一张图。先生成正面，通过后把正面也作为侧面与背面的共同参考。

### 主角正面

> 严格依据上传参考图中的主角身份制作三维建模用角色正面设定。年轻东方男性，清瘦而有力量的成年比例，黑色长发半束、散碎刘海和长发束；黑色不对称披肩与墨染白色交领内衫，腰间少量暗朱红系带、金属小挂饰，分片长衣摆，黑色护臂和长靴。完整全身，正交正面视角，无透视缩短；自然 A-pose，双臂向外下垂约三十度，双脚分开，手指可辨。保留原角色的脸、服装层次和配色，不重新设计人物。中性柔和照明，浅灰纯色背景，头顶与脚底完整留白。画面只出现这一个角色，没有武器遮挡身体，没有文字、编号、刀光、粒子、残影、场景或版式。1024×1536。

### 主角侧面 / 背面

> 使用同一参考角色和已确认的正面设定，输出同一 A-pose 的严格正交右侧面全身图【背面图时改为严格正交背面】。人物身高、头身比、衣服长度、腰带高度和发型必须与正面一致。清楚显示鼻额下巴轮廓、衣服叠层、发束长度与刀鞘挂点【背面图时重点显示后脑、披肩、背部衣片和腰后挂点】。浅灰纯色背景，光照中性。只出现一个人物，无文字、无动作、无特效，完整头脚。1024×1536。

### 刀与刀鞘

> 依据参考图主角的武器，制作三维建模用武器设定：狭长略弯的单刃刀，冷银刀刃，深色缠柄，低调金属护手；配套黑色刀鞘和少量暗朱红系绳。刀和刀鞘分别完整展示，平行横放，严格正交侧视，尺寸可比较，形状不遮挡。不出现人物、手、文字、刀光或场景。中性照明，浅灰纯色背景，2048×1024。

### 白袍剑客

> 与参考图相同的水墨武侠材质和成年人体比例，设计白袍剑客 Boss。身形修长，面容冷峻，发束整洁，白色长袍、浅灰内层、墨色窄腰带，衣服轮廓克制整齐，与主角的破墨黑白衣摆形成明显区别。佩戴可收鞘的细长剑。先输出一张严格正交正面全身 A-pose 设定，武器单独放在旁边，不遮挡身体。浅灰纯色背景，无文字、无特效、无场景，1024×1536。确认正面后再生成同一人物的侧面、背面。

## 暂时不用生成

现有代码已经负责雨、雾、冲击圈、火花、飞墨、残影、白色刀路、朱红绝技、竹子折断、镜头、命中停顿和合成音效。第一版也不需要表情合集、宣传立绘或十张地图。

当前采用三维角色，所以跑、砍、格挡优先由关节动画完成，不需要先生成上百张角色动作小图。可以补关键姿势参考，但不要把它当作可直接播放的三维动画。

如果之后交付成品三维角色，使用 `.glb`，附带 `.blend` 源文件、UV、基础颜色贴图、蒙皮权重和命名骨骼。建议主角约 15k–30k 三角形、1–2 张 2048 贴图；刀、刀鞘分别为独立对象，发束和主要衣摆可驱动。动画按 Idle / Run / Jump / Slash1 / Slash2 / Slash3 / Upper / Air / Dive / Dash / Guard / Hurt / Execute / Ultimate / Death 拆分，角色位移由游戏负责。以上为目标交付规格，当前底稿尚不满足蒙皮与动画要求。

生成一张“贴图风格图”不等于生成了可直接套用的角色贴图；正式贴图需要对应最终模型的 UV。先锁定角色结构，再做贴图与蒙皮。

工具依据：[Three.js 官方 GLTFExporter 文档](https://threejs.org/docs/pages/GLTFExporter.html)。导出器随工具目录按 Three.js 的 MIT 许可证保留，只调整了本地模块导入路径。
