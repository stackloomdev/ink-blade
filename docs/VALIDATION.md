## 本轮步态修正

- 原来的全局时间正弦摆腿改为按实际位移推进的支撑、蹬地、回收、前摆。两腿相隔半周期，慢步有双脚支撑，快跑有腾空段。
- 髋、膝、踝分开求解，双膝保持向前弯；脚掌独立旋转，站稳的一只脚固定在世界坐标。重心按步态轻微起伏，不再跟随最低的靴子上下跳。
- 远侧手臂屈肘摆动，与迈步相配合；主角跑步时刀尖保持接近地面。水花和脚步声在落脚时触发。
- 检视页检查了主角、白袍剑客的行走与奔跑，并对支撑、回收和腾空姿势逐帧观察。保留衣袍在腿前的遮挡，避免裁切留下静止的小腿或衣袍空洞。
- 步态测试覆盖 30 / 60 / 120 FPS、加速时支撑脚位置、暂停不走步、反向 / 重开清除旧落脚点、两名角色的骨段长度、膝盖方向、脚掌不穿地与周期连续性。
- `tools/locomotion-check.js` 在实际游戏页面通过正常按键完成起跑、停步、立即反向、暂停恢复和接斩。开发页采样 237 帧，其中 87 次相邻支撑帧的脚掌水平位移误差为 0；暂停期间位置和步态相位保持一致。同一检查在最终 `/dist/` 生产页面再次通过。

这些检查证明具体的落脚约束、动作切换和画面可用性，不把“坐标有限”或“通关成功”等同于动画审美达标。新的姿势仍是静态原画的分层变形；检视页提供正常播放、¼ 慢放和 ⅒ 慢放，供直接评估动作。

## “1:1”的具体边界

已确认的是原始素材身份、轮廓比例和不透明内部的颜色取样。透明发丝 / 衣摆边缘来自分割，新增动作由原画分层、邻近服装衬层和骨架变形制作。用户提供的是三视图，没有完整逐帧动画，因此不声称“所有战斗姿势逐帧等同于源动画”。

`tools/character-study.html` 使用同一游戏渲染类，允许原图对照、切换视图、动作定格和命中时间检查。开发记录保存在被 Git 忽略的 `artifacts/qa/` 中。
