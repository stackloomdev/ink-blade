## “1:1”的具体边界

已确认的是原始素材身份、轮廓比例和不透明内部的颜色取样。透明发丝 / 衣摆边缘来自分割，新增动作由原画分层、邻近服装衬层和骨架变形制作。用户提供的是三视图，没有完整逐帧动画，因此不声称“所有战斗姿势逐帧等同于源动画”。

`tools/character-study.html` 使用同一游戏渲染类，允许原图对照、切换视图、动作定格和命中时间检查。开发记录保存在被 Git 忽略的 `artifacts/qa/` 中。
